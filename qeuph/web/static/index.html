Step-by-Step Mainnet Launch Runbook

          
Exact terminal commands to deploy seed nodes, peer validators, wallets, and solo miners.

        


        

          
          

            

              Step 1: Verify System & Cryptographic Preflight
              
            

            
Checks ports 19090/19091 availability, data directory permissions, ML-DSA-87 signatures, and emission constants.

            
python3 -m qeuph.cli.main preflight --network mainnet

          


          
          

            

              Step 2: Verify Whitepaper Consensus Invariants
              
            

            
Audits block time (300s), retarget interval (2048 blocks), emission decay (2/3 ratio), and genesis coinbase message.

            
python3 tools/wp_conformance.py

          


          
          

            

              Step 3: Launch First Mainnet Seed Node (Bootstrap Node A)
              
            

            
Starts the first authoritative daemon listening on public P2P port 19090 with secured local JSON-RPC on port 19091.

            
python3 -m qeuph.cli.main node --network mainnet --datadir ~/.qeuph/mainnet-seed --listen 0.0.0.0:19090 --rpc 127.0.0.1:19091

          


          
          

            

              Step 4: Connect Peer Nodes to Form Multi-Node Mesh
              
            

            
Additional nodes connect into the seed node. Replace SEED_IP with your seed node's IP address or hostname.

            
python3 -m qeuph.cli.main node --network mainnet --datadir ~/.qeuph/mainnet-node2 --connect SEED_IP:19090

          


          
          

            

              Step 5: Launch Web Explorer & Node Console
              
            

            
Deploys this Web UI connected directly to the P2P mesh, synchronizing headers, blocks, and mempool transactions in real time.

            
python3 -m qeuph.web.server --network mainnet --port 3000 --connect SEED_IP:19090

          


          
          

            

              Step 6: Create Post-Quantum Vault Wallet
              
            

            
Generates a BIP-39 mnemonic phrase and derives your initial Bech32m address (quh1...) encrypted with your passphrase.

            
python3 -m qeuph.cli.main wallet create --network mainnet

          


          
          

            

              Step 7: Launch Solo Miner on Mainnet Tip
              
            

            
Begins grinding 16-byte nonces over the double SHA3-512 PoW algorithm. Block rewards pay directly to your quantum address.

            
python3 -m qeuph.cli.main mine --network mainnet --threads 4 --payout YOUR_MAINNET_ADDRESS
