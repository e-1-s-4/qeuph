A solo miner only finds a block by luck. On mainnet the expected wait at difficulty 1 is about 268 million hashes; the network as a whole has that many times its own hashrate.

two-thirding schedule

reward(h) = floor(50 QUH × (2/3)^floor(h / 210000)), floored to whole quphi every epoch exactly as Bitcoin floors its halvings. The geometric series converges on the 31,500,000 QUH cap; the iterated floor leaves the exact emission 0.1407 QUH below it.

FIPS 204 ML-DSA-87 parameters

qeuph/crypto/fips204.py is a dependency-free reference implementation of FIPS 204 Algorithms 5–48. Seeded keygen is byte-identical to the OpenSSL / AWS-LC backend and each backend verifies the other's signatures, so every signature on the chain has two independent audit paths.

what this is

Qeuph (QUH) is a quantum-resistant proof-of-work ledger. Every signature on the chain is an ML-DSA-87 lattice signature (FIPS 204, NIST security category 5) and every identifier — transaction ids, block ids, addresses, the proof-of-work digest — is a double SHA3-512 hash, so no elliptic curve and no SHA-2 commitment appears anywhere in the consensus path.

The ledger is UTXO-based and every input additionally carries a txnonce: the per-address strictly-increasing counter that makes ordering deterministic and replay impossible even when a spent output is reconstructed exactly.

Emission uses two-thirding rather than halving: every 210,000 blocks the reward becomes two-thirds of the previous one, floored to whole quphi, converging on the 31,500,000 QUH cap over roughly 108 years.
